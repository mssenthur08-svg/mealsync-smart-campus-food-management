Local IndexedDB Privacy Architecture

Active Database: MealSync_Campus_LocalDB

Storage Engine: Browser IndexedDB (app records stored on this device)

App data uploads: No application-data upload is implemented

External assets: Tailwind CSS and Chart.js are loaded from public CDNs when the page opens.

MealSync stores its application records locally in this browser. This is local storage, not end-to-end encryption.

  • Local records: Application state is stored in this browser's IndexedDB. Do not enter real student identifiers into this demo unless the device and browser profile are managed securely.
  • Local processing: Demand calculations run in browser JavaScript; no AI service connection is configured in this file.
  • Browser scope: Data is available to this site's browser origin and may be cleared by browser storage settings.
  • Synthetic Data: All demo hostel cards use generated mock data to safeguard student privacy.
